SOP: Preparing the Weekly Status Report

A step-by-step procedure anyone on the team can follow, so the weekly report goes out the same way every Friday.

SOP ID: PMO-003Version: 1.2Owner: Rio M. SosaReview: Every quarter

Purpose

Give managers a consistent, accurate summary of project progress every Friday by 4:00 PM.

Procedure

  1. Thursday 3:00 PM - Request updatesSend the update request template to each task owner in the team chat.
  2. Friday 10:00 AM - Update the trackerRecord status and progress for every task. Chase missing updates directly.
  3. Friday 12:00 PM - Check the numbersConfirm totals, due dates and overdue items match the tracker. Flag anything overdue as At risk.
  4. Friday 2:00 PM - Draft the reportFill in the report template: overall status, done, next, risks, decisions needed.
  5. Friday 3:00 PM - ReviewSend to the project lead for a quick check. Apply edits.
  6. Friday 4:00 PM - Send and fileEmail the report to stakeholders and save a PDF copy in Reports / 2026 / Week-NN.

Quality checklist

  • Every risk has an owner and a next step
  • Dates use the same format (Mar 07)
  • Report fits on one page
  • File name follows WSR_Project_Week-NN.pdf

Prepared by Rio M. Sosa as a portfolio sample. Brightline Studio is a fictional company; names, dates and figures are illustrative.
